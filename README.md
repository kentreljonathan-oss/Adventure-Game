# Mysterious Forest Adventure

A simple text-based adventure game built in Python. The player makes choices that affect their inventory, score, and which ending they reach.

## About the Game

You wake up at the edge of a dark forest, where rumors of hidden treasure have drawn you in. Every choice you make, from which path you take to how you handle a goblin encounter, shapes how your story ends. There are multiple possible endings depending on your decisions and final score.

## Features

- A branching storyline with three major decision points
- An inventory system that tracks items you collect, use, or lose
- A goblin encounter with fight, flee, or bribe options
- A score counter that rises and falls based on your choices
- Multiple possible endings
- A play again or quit option at the end of each round

## How to Play

1. Clone or download this repository
2. Make sure Python 3 is installed on your machine
3. Run the game from your terminal:

```
python3 adventure_game.py
```

4. Follow the on-screen prompts and type your choice when asked
5. At the end of the game, type `yes` to play again or `no` to quit

## Running It in GitHub Codespaces

If you do not want to install Python locally, you can run the game directly in your browser:

1. Click the green **Code** button on this repository
2. Select the **Codespaces** tab
3. Click **Create codespace on main**
4. Once the environment loads, open the terminal and run:

```
python3 adventure_game.py
```

## Example Choices

1. Enter the dark forest

Each choice leads to a different item, a different path through the story, and a different outcome.
